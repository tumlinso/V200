# V200

Developing a process-scoped CUDA compatibility layer that presents an NVLink-connected V100 pair as one application-visible device. The first workload is the existing llama.cpp / llama-server installation.

Start with [planning](planning/README.md) and the [execution plan](planning/EXECUTION_PLAN.md). The extracted bootstrap is preserved under `planning/v200-bootstrap/`.

Implementation has not started. Package and CPU validation are not evidence of a working virtual GPU, application compatibility or acceleration. Todo authority and its generated projections track the adopted outcome plan.

Git remote: <https://github.com/tumlinso/V200.git>.
