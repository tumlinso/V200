4 exact physical UUIDs, 300 seconds child wall cap, 14336 MiB application allocation cap per GPU, at most 4 CPU threads. Build first. The actual fixture must check headroom and enforce its allocation cap; context overhead is additional and reported. No test window is granted by this document.

- Each pair separately qualified
- Both logical IDs and full directed physical topology identified
- Explicit four-GPU window

1. Verify two logical devices and both underlying UUID pairs
2. Check eligible endpoint copies in each required direction
3. Do not advertise arbitrary peer-pointer access when a constituent cannot map it
4. Run one ordinary two-logical-device consumer configuration and matched native control
5. Record inter-pair transfer cost and all owned-resource release

- Topology is respected internally
- Pair and four-device results remain separate

## Stop/defer conditions
