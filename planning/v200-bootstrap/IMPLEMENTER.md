## First useful work

Adopt the package into an authorized V200 repository without disturbing existing work. Pin the actual target executable and stack. Do CPU source/ELF analysis and build the two foundation examples. Establish the front-door ABI closure before broad implementation. Produce a legal pair-VMM and completion proof with one short admitted bundle, then integrate a real single-device consumer quickly.

Do not start by implementing every CUDA API or a universal SASS rewriter. Do not mistake a successful one-device enumeration spoof for a virtual accelerator. A cuBLAS-only route will miss custom inference kernels; a malloc-only route may miss direct application VMM. These are specifically investigated in the design.
